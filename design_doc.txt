Web App: Lincoln's Birthday Quest
Updated for Lincoln's 9th Birthday (2026)
==========================================
Originally created for Lily's 11th Birthday (2025). This document reflects the current
state of the game as built — the original design doc was written before development and
the game has evolved beyond it during build.

1. PROJECT OVERVIEW
The game is a single-page web application (index.html) with a wizard/magic theme.
Lincoln interacts with a crystal ball that plays audio clues guiding him to find physical
4-digit codes hidden around the house. Each code unlocks a puzzle by matching symbols
to the correct sequence. There are 10 puzzles in total. The game ends with a multi-phase
ending sequence that reveals the location of Lincoln's birthday present.

2. TARGET USER
Primary User: Lincoln (Dean's son, born 2017, approx. 9 years old)
Considerations: Puzzles and interactions should be intuitive and engaging for this age.

3. CORE GAMEPLAY LOOP
(A) Password screen: password is "ninetoday2026"
(B) Birthday modal dismisses, then crystal ball auto-plays intro.mp3
(C) For each of the 10 puzzles:
    - Crystal ball plays a location clue (audio)
    - Lincoln finds the hidden 4-digit code in the house
    - On the puzzle screen, Lincoln drags symbols into 4 slots matching the code
    - Correct code: door unlocks with animation + sound, next clue plays automatically
    - Wrong code: shake animation + random nope sound
(D) After all 10 doors: ending sequence plays (are-you-sure1.mp3, are-you-sure2.mp3,
    location.mp3) revealing the gift location
(E) Lincoln can tap the crystal ball any time to replay the current clue

6. VISUAL DESIGN
    Theme: Wizard / Magic (dark blues, purples, gold accents)
    Fonts: MedievalSharp (headings), IM Fell English SC (body)
    Crystal ball: images/orb.png, orb2.png, orb3.png
    Orb glow pulses in sync with audio volume via Web Audio API
    Symbols: 16 SVG shapes, 8 per puzzle (deterministic based on puzzle seed)
    Doors: SVG shapes injected inline, unique per puzzle

7. SCENES
